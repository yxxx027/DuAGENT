# GenPilotLight — 详细任务分工和时间安排

***

## 一、项目总览

### 1.1 项目名称

GenPilotLight：基于结构化 Prompt 解析与 Negative Prompt 的轻量图像生成优化 Agent

### 1.2 核心改进

| 改进点   | 名称                 | 核心思想                             | LLM 调用   |
| ----- | ------------------ | -------------------------------- | -------- |
| 改进点 1 | 结构化 Prompt 解析      | 将自由文本解析为结构化 JSON，再重组为更精确的 Prompt | 每条 1 次   |
| 改进点 2 | Negative Prompt 生成 | 基于结构化结果，规则生成"不要画什么"              | 0 次（纯规则） |
| 评测    | CLIP 自动评分          | 本地 CLIP 模型计算文本-图像对齐度             | 0 次（本地）  |

### 1.3 团队角色

| 编号       | 角色        | 核心职责                                                               |
| -------- | --------- | ------------------------------------------------------------------ |
| 成员 0（组长） | 架构集成 & 汇报 | 环境搭建、Baseline 跑通、主脚本、代码合并、PPT、论文 Introduction、related works        |
| 成员 1     | 改进点 1 开发  | 结构化 Prompt 解析模块 + Prompt 模板、跑通 + 论文 Methods                        |
| 成员 2     | 改进点 2 开发  | Negative Prompt 生成模块 + 规则库、跑通 + 论文 Methods                         |
| 成员 3     | 实验评测      | CLIP 评分器 + 可视化 + 测试 Prompt + 论文 Experiments、conclusion、汇总与ICLR模版融入 |

## 六、风险与应对

| 风险                 | 影响            | 应对措施                       |
| ------------------ | ------------- | -------------------------- |
| DeepSeek API 限速    | 结构化解析慢        | 减少并发，增加 sleep              |
| 结构化解析精度不够          | 重组 Prompt 质量差 | 优化模板，增加 few-shot           |
| Negative Prompt 过长 | 图像质量下降        | 用 `prune_negations()` 控制长度 |
| CLIP 评分不稳定         | 实验结果波动        | 多次评分取平均                    |
| 集成时接口不兼容           | 合并代码报错        | 严格遵循接口规范，成员 0 提前联调         |
