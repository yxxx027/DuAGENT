# GenPilotLight — 图像生成模型下载指南

***

## 一、模型选择

根据你的 GPU 显存选择合适的模型：

| 模型 | 显存需求 | 效果 | 许可审批 | 推荐场景 |
|------|---------|------|---------|---------|
| FLUX.1-schnell | ~30GB | ⭐⭐⭐ | 需要同意 | 30GB+ 显存 GPU |
| SD3-medium | ~10GB | ⭐⭐ | 不需要 | 12GB+ 显存 GPU |
| SD 2.1 | ~5GB | ⭐⭐ | 不需要 | 8GB+ 显存 GPU |
| **SD 1.5** | **~4GB** | **⭐** | **不需要** | **4GB+ 显存 GPU（本项目默认）** |

> 本项目默认使用 **SD 1.5**，在 4×GTX 1080 Ti (11GB) 服务器上稳定运行。

***

## 二、SD 1.5 下载（推荐，本项目默认）

### 2.1 直接下载

```bash
conda activate genpilot
export HF_ENDPOINT=https://hf-mirror.com
huggingface-cli download runwayml/stable-diffusion-v1-5 --local-dir ~/models/sd1.5
```

### 2.2 验证下载完整

```bash
ls ~/models/sd1.5/model_index.json
ls ~/models/sd1.5/vae/diffusion_pytorch_model.safetensors
```

两个文件都存在才算下载完整。

### 2.3 快速测试

```bash
python -c "
import torch
from diffusers import StableDiffusionPipeline
pipe = StableDiffusionPipeline.from_pretrained(
    '/home/user5/models/sd1.5',
    torch_dtype=torch.float16,
    local_files_only=True
)
pipe.to('cuda:0')
img = pipe('a red apple', width=512, height=512, num_inference_steps=20).images[0]
img.save('/tmp/test_sd15.png')
print('SD1.5 OK')
"
```

### 2.4 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| `header too small` | 下载不完整/中断 | `rm -rf ~/models/sd1.5` 后重新下载 |
| 下载速度慢 | HuggingFace 国内访问慢 | 使用 `HF_ENDPOINT=https://hf-mirror.com` |
| 下载中断 | 网络不稳定 | 用 `nohup` 防止断连（见下方） |

### 2.5 防断连下载

```bash
nohup huggingface-cli download runwayml/stable-diffusion-v1-5 \
  --local-dir ~/models/sd1.5 > ~/download_sd15.log 2>&1 &

# 查看进度
tail -f ~/download_sd15.log
```

## 五、FLUX.1-schnell 下载

### 5.1 前置条件：同意许可协议

1. 浏览器打开 [https://huggingface.co/black-forest-labs/FLUX.1-schnell](https://huggingface.co/black-forest-labs/FLUX.1-schnell)
2. 登录 HuggingFace 账号
3. 点击 **"Agree and access repository"**

### 5.2 登录 HuggingFace

```bash
huggingface-cli login
# 粘贴你的 HuggingFace Token（从 https://huggingface.co/settings/tokens 获取）
```

### 5.3 下载

```bash
export HF_ENDPOINT=https://hf-mirror.com
huggingface-cli download black-forest-labs/FLUX.1-schnell --local-dir ~/models/FLUX.1-schnell
```

### 5.4 验证

```bash
ls ~/models/FLUX.1-schnell/model_index.json
```

> ⚠️ FLUX 需要 ~30GB 显存，4×GTX 1080 Ti 无法运行。仅在有更大显存 GPU 时使用。

使用时修改参数：

```bash
--model_name flux --model_path /home/user5/models/FLUX.1-schnell
```

## 六、CLIP 模型下载

CLIP 模型用于自动评分，首次运行时自动下载，也可手动预下载：

```bash
export HF_ENDPOINT=https://hf-mirror.com
python -c "
from transformers import CLIPModel, CLIPProcessor
CLIPModel.from_pretrained('openai/clip-vit-large-patch14')
CLIPProcessor.from_pretrained('openai/clip-vit-large-patch14')
print('CLIP model downloaded!')
"
```

| 属性 | 值 |
|------|-----|
| 模型名 | `openai/clip-vit-large-patch14` |
| 大小 | ~1.7GB |
| 显存 | ~2GB |
| 用途 | 文本-图像对齐度评分 |
| 无需 API | 本地运行，零成本 |

## 七、HuggingFace 镜像配置

国内服务器访问 HuggingFace 可能很慢，建议始终配置镜像：

```bash
# 临时生效
export HF_ENDPOINT=https://hf-mirror.com

# 永久生效（写入 .bashrc）
echo 'export HF_ENDPOINT=https://hf-mirror.com' >> ~/.bashrc
source ~/.bashrc
```

## 八、模型文件完整性检查

下载完成后，运行以下命令检查所有模型是否完整：

```bash
echo "=== 模型完整性检查 ==="

# SD 1.5
if [ -f ~/models/sd1.5/model_index.json ]; then
    echo "✅ SD 1.5: OK"
else
    echo "❌ SD 1.5: 缺失 model_index.json"
fi

# SD 2.1
if [ -f ~/models/sd2.1/model_index.json ]; then
    echo "✅ SD 2.1: OK"
else
    echo "⚠️  SD 2.1: 未下载（可选）"
fi

# SD3
if [ -f ~/models/sd3/model_index.json ]; then
    echo "✅ SD3: OK"
else
    echo "⚠️  SD3: 未下载（可选）"
fi

# FLUX
if [ -f ~/models/FLUX.1-schnell/model_index.json ]; then
    echo "✅ FLUX: OK"
else
    echo "⚠️  FLUX: 未下载（可选，需大显存）"
fi

echo "=== 检查完成 ==="
```
